# Конфиденциальность и данные

## Где хранятся дела

Начиная с Beta 2 мастерские проекты Detective Board хранятся локально в одной постоянной системной папке **Detective Board** на компьютере пользователя. Она не зависит от расположения portable `.exe` или папки конкретной версии программы.

Точный путь можно открыть из программы через `? Как пользоваться → Данные и обновления → Открыть папку данных`.

Внутри находятся:

- `data/store.json` — мастерские дела;
- `backups/` — автоматические резервные копии;
- `settings/` — локальные настройки приложения и публикации.

Обычная работа с доской не требует аккаунта Detective Board и не требует собственного облачного сервера проекта.

## Резервные копии

Beta 2 автоматически создаёт локальные резервные копии при смене версии и не чаще одного раза в день. Пользователь также может вручную создать или восстановить backup.

Эти копии остаются на компьютере пользователя и сами по себе никуда не отправляются.

## Что отправляется в интернет

Само редактирование дела происходит локально.

Данные отправляются во внешний сервис только после явного действия пользователя, связанного с публикацией Player Viewer. При автоматической публикации приложение обращается к API Netlify и отправляет туда подготовленную публичную версию доски.

## Что не должно попадать в Player Viewer

Публичный экспорт формируется отдельно от мастерского проекта. В него не должны включаться:

- мастерские заметки;
- скрытые карточки;
- скрытые факты;
- скрытые связи;
- закрытые поля карточек;
- данные раздела «Истина мастера».

Перед публикацией рекомендуется проверить состояние через режим **«Глазами игроков»**.

## Netlify Personal Access Token

Для автоматической публикации в Netlify пользователь может один раз указать Personal Access Token. Токен предназначен только для обращения приложения к Netlify API и хранится локально настройками приложения.

Не публикуйте токен в Issues, скриншотах, диагностике, логах или общедоступных файлах. Если токен случайно раскрыт, отзовите его в настройках Netlify и создайте новый.

## Телеметрия

В текущей публичной бете Detective Board нет собственной системы аналитики/телеметрии проекта.
