# FAQ — Detective Board

## Нужно ли устанавливать Node.js?

Нет. Для обычного пользователя релизный `.exe` является автономной Windows-сборкой.

## Нужно ли устанавливать программу?

Нет. Приложение распространяется как portable-приложение. Достаточно распаковать ZIP и запустить `.exe`.

## Почему Windows предупреждает о неизвестном издателе?

Публичная бета пока не подписана коммерческим code-signing сертификатом. Поэтому SmartScreen может показать предупреждение даже для неизменённого релизного файла.

Контрольная сумма официальной сборки публикуется рядом с релизом в `SHA256.txt`.

## Где хранятся мои дела?

Начиная с Beta 2 — в одной постоянной системной папке **Detective Board**, а не рядом с portable `.exe`.

Точный путь можно посмотреть через `? Как пользоваться → Данные и обновления → Открыть папку данных`.

Поэтому замена `.exe` новой версией сама по себе не должна удалять существующие доски.

## Как сделать резервную копию?

Откройте `? Как пользоваться → Данные и обновления → Создать резервную копию`.

Кроме ручных копий приложение автоматически создаёт backup при смене версии, не чаще одного раза в день и перед удалением доски.

## Что делать, если старые дела не появились после обновления?

Не удаляйте старую папку Preview/Beta. Найдите в ней `data/store.json` и используйте `? Как пользоваться → Данные и обновления → Импортировать старый store.json`.

Импорт добавляет старые доски к текущим, а не заменяет их.

## Нужен ли интернет для работы?

Для создания и редактирования расследований — нет.

Интернет нужен для автоматической публикации Player Viewer и других действий, которые напрямую используют внешний сервис.

## Могут ли игроки изменить мою доску?

Нет. Player Viewer — отдельная read-only версия.

## Могут ли игроки через DevTools увидеть секреты мастера?

Скрытые мастерские элементы не должны входить в публичный экспорт вообще. Они не просто скрываются стилями страницы.

## Как обновить доску игроков, не меняя ссылку?

В Cloudflare у каждой доски есть своя постоянная ссылка. После изменения открытой информации нажмите **«Обновить публичную доску»**, дождитесь завершения и обновите страницу у игроков. Другие доски не заменяются. Для существующих Netlify-публикаций обновление также сохраняет привязку.

## Как перемещаться по большой доске?

Зажмите колёсико мыши и двигайте мышь. Также работает `Space + мышь`. Обычное вращение колеса меняет масштаб.

## Что делать перед важной игровой сессией?

Полезно открыть дело и убедиться, что оно сохранилось, сделать ручной backup, проверить режим «Глазами игроков» и при использовании Player Viewer открыть публичную ссылку с телефона.

## Где сообщить о проблеме?

Откройте GitHub Issues и выберите шаблон Bug report.

## С чего начать публикацию через Cloudflare?

Откройте [пошаговый гайд](../PUBLISHING.md). В ZIP также есть автономный CLOUDFLARE-GUIDE.html с иллюстрациями. Account ID можно вставить целой ссылкой из адресной строки панели. API Token нужен только мастеру; игрокам отправляйте публичную ссылку.

## Это бесплатно и без ограничений?

Приложение не продаёт кредиты публикации. Cloudflare имеет собственный бесплатный план и ограничения; они описаны в гайде. Бесплатный план не означает неограниченное число загрузок. Неизменённый снимок приложение повторно не отправляет.

## Нужно ли держать компьютер мастера включённым?

После успешной публикации — нет. Доска хранится на выбранном хостинге. Игроки видят последний опубликованный снимок. Живой сервер и совместное редактирование в эту версию не входят.

## Почему изменения появились не сразу?

Подготовка версии на Cloudflare может занять некоторое время. Дождитесь успешного результата в приложении и обновите страницу по постоянной ссылке доски. Не запускайте много повторных загрузок подряд.

## Скрытая карточка точно исчезнет из старых публикаций?

Новая публикация не включает скрытые данные, но исторические deployments и уже сохранённые игроками копии могут остаться. Публичная ссылка не является паролем.

## Что делать с большой доской и фотографиями?

В «Экспорт игрокам» доступна команда «Уменьшить изображения». Она может ухудшить мелкие надписи; изменение можно отменить Ctrl+Z. Старые картинки не пережимаются при открытии. Если прежние данные не проходят новые пределы, сохраните оригинал и следуйте [инструкции обновления](../UPDATING.md).
