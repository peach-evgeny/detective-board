## Как выглядит Detective Board

### Полная доска мастера

![Общий вид расследования](docs/images/01-overview-master-board.png)

На одной доске можно собрать персонажей, места, улики и связи между ними, а затем постепенно раскрывать расследование игрокам.

### Конструктор расследования

![Истина мастера и этапы раскрытия](docs/images/04-case-constructor.png)

Сначала фиксируется полная версия произошедшего, затем карточки, факты и связи распределяются по этапам раскрытия.
