# Detective Board: аудит безопасности и производительности

**Версия:** 1.0.0-beta.3.6. **Дата:** 16 октября 2026. Сравнение с beta.3.5.

Проведён аудит исходников Electron, локального HTTP API, хранилища, импорта, редактора, изображений и публичного экспорта. Исправления реализованы. Это инженерная проверка доступного исходного кода и локальных сценариев, не сертификат безопасности и не проверка готового EXE на компьютере пользователя.

## Находки и исправления

| Приоритет | Что было | Что изменено |
|---|---|---|
| Высокий | Локальный API доверял переданному `userId`; старые маршруты участников, приглашений и SSE оставались доступны. Отдельный запуск сервера слушал все интерфейсы. | Только `127.0.0.1`, случайный 256-битный ключ текущего запуска, проверка Host/Origin/Sec-Fetch-Site и JSON. Ключ выдаётся через доверенный IPC главному frame. Маршруты мультиплеера удалены. |
| Высокий | Интерфейс сообщал «сохранено» до записи; асинхронные записи использовали один `.tmp`; ошибки диска оставались в консоли. Последние изменения могли пропасть при выходе. | Последовательная очередь, уникальный временный файл, fsync и атомарная замена. Ответ после записи. При ошибке откат серверного состояния, сохранение правок в редакторе и явный повтор. Выход и обычное закрытие ждут сохранения. |
| Высокий | Ошибка чтения `store.json` превращалась в пустую базу с риском перезаписи. | Повреждённые и неподдерживаемые данные блокируют запуск/импорт, исходный файл остаётся нетронутым. |
| Средний | Часть IPC не проверяла отправителя; `openPath` принимал произвольный путь. | Общая проверка точного главного frame для всех IPC. Открываются только пути экспорта, созданные в текущем запуске. Внешние URL ограничены HTTPS без credentials и нестандартного порта. |
| Средний | Импорт позволял произвольные идентификаторы, внешние URL изображений, повреждённые структуры и чрезмерные размеры. | Проверка структуры, уникальных ID, чисел, количества элементов, данных картинок и их заголовков. Опасные ключи JSON и SVG/внешние картинки отклоняются. Атрибуты картинок дополнительно экранируются. |
| Средний | Экспорт рекурсивно удалял уже существующую одноимённую папку. | Уникальная новая папка; существующая папка не удаляется. Перед удалением доски создаётся резервная копия хранилища. |
| Средний | Устаревший Electron 35.7.5; дополнительные полномочия браузера не были явно запрещены. | Electron 44.8.0, electron-builder 26.15.3; явные sandbox/context isolation/web security, запрет webview, новых окон и разрешений браузера. |
| Защита экспорта | У Player Viewer не было ограничивающей CSP. | Автономный HTML допускает только два встроенных скрипта с конкретными SHA-256-хешами. Запрещены сетевые запросы, формы, frames и плагины. Положительная схема публичных полей сохранена. |

До исправления Desktop уже привязывал сервер к loopback. Основная угроза API касалась запросов с того же компьютера и межсайтовых запросов; отдельный старый dev-сервер дополнительно открывал сетевой интерфейс. Удалённый веб-сайт после исправления не получает доступ, зная только `master-local`. Защита не предназначена для противодействия вредоносной программе, уже работающей под тем же пользователем ОС.

## Производительность: одинаковые данные до и после

Среда: Linux, Node 24.19, headless Chromium 153 через Playwright, GPU отключён. Это не измерение на Windows пользователя. Синтетические изображения содержат шум, цвет и разные подписи; 100 разных WebP по 1000×700 px, 99 связей. Исходный JSON: **30 064 077 байт**.

| Измерение | beta.3.5 | beta.3.6 |
|---|---:|---:|
| Первая синхронная отрисовка | 201 мс | 221 мс |
| Повторная отрисовка при выборе, медиана 20 действий | 144 мс | 16,6 мс |
| Худшее из этих 20 действий | 159 мс | 26,8 мс |
| DOM-узел картинки сохраняется | Нет | Да |
| 100 снимков Undo | 24,5 мс | 24,3 мс |
| Подготовка изменения координаты | 1,2 мс | 0,9 мс |
| Размер изменения координаты без HTTP-обёртки | 99 байт | 99 байт |

Ускорена повторная отрисовка примерно в **8,7 раза**. Первое открытие не ускорилось: все карточки всё ещё создаются сразу. Копирование состояния и отправка только изменённых полей уже были оптимизированы в beta.3.5; они не объявляются новыми улучшениями.

Причина ускорения: редактор сохраняет DOM карточки и её картинку, обновляя положение/выделение отдельно от содержимого. Player Viewer также не пересоздаёт все изображения при выборе карточки. Журнал запрашивает только записи активности, а не всю доску с картинками. Сервер не сериализует неизменённые изображения для классификации перемещения.

## Сквозная проверка 100 картинок

Настоящий локальный сервер, настоящий браузер и временный файл хранилища; Cloudflare здесь не вызывался.

- Суммарные строки изображений уменьшились с **30 047 228** до **14 315 776 байт**.
- Крупнейшая сохранённая картинка: **145 087 байт**, ниже ограничения 180 КиБ.
- Автономный публичный HTML: **14 376 535 байт (13,7 МиБ)**.
- Первая запись всех 100 изображений: около **1,98 с**; запись последующего перемещения: около **144 мс**, без 280 мс задержки автосохранения интерфейса.
- Проверены последняя правка перед выходом, повторное открытие всех 100 карточек, сохранение на диске, отказ от файла 21 МиБ, поиск/выбор в автономном viewer и CSP без ошибок консоли.

Это один локальный замер, не обещание одинаковой скорости для любых фотографий и компьютеров. Старые тяжёлые картинки не меняются при открытии. Кнопка «Уменьшить изображения» действует после подтверждения и поддерживает Ctrl+Z. Размеры новых картинок ограничены при добавлении; снижение качества может ухудшить мелкие надписи. Исходные файлы пользователя не изменяются.

## Защитные пределы

| Объект | Предел |
|---|---:|
| Исходный файл изображения | 20 МиБ |
| Размер декодируемой картинки по заголовку | 32 Мп, до 16 000 px по стороне |
| Новая сохранённая картинка | До 1200 px по длинной стороне, до 180 КиБ data URL |
| Существующее встроенное изображение при импорте | До 6 МиБ data URL (примерно 4,5 МиБ бинарных данных) |
| Изображения одной доски | 64 МиБ строк data URL |
| Объекты / связи / этапы одной доски | 1000 / 3000 / 100 |
| Доски / файл хранилища | 200 / 256 МиБ |
| Один запрос изменения | 32 МиБ |
| Отдельное текстовое поле | 100 000 символов |
| Публичный файл Cloudflare | 25 МиБ, с точной проверкой перед отправкой |

Если старые данные превышают пределы, приложение сообщает об отказе и сохраняет оригинал. Порядок восстановления и отката описан в UPDATING.md. Заголовки изображений проверяются по первым 256 КиБ: редкие JPEG с очень большими метаданными могут требовать пересохранения. GIF при добавлении становится неподвижной картинкой.

## Удалённое наследие

Удалены серверные SSE/heartbeat/presence, приглашения и вход по ссылкам, передача курсоров, смена ролей и удаление участников; клиентские обработчики сетевых событий, скрытые диалоги профиля/участников и соответствующие стили. Исторические имена в журнале сохранены, старые локальные доски остаются доступны мастеру.

Удалены неиспользуемые service worker, manifest и PWA-иконка шаблона. ZIP экспорта содержит автономный HTML и README, без дублирующего `board-data.js` и копии всех ресурсов. Старые Cloudflare deployments удалением исходников не затронуты. Netlify оставлен: он по-прежнему доступен в интерфейсе как дополнительный способ публикации и не является мёртвым кодом.

## Проверки и остаточные риски

**52 автоматических теста проходят.** Они покрывают изоляцию API/IPC, некорректные данные, ошибку диска, последовательные записи, восстановимость удаления, повреждённый store, слишком большое тело запроса, закрытие с последней правкой, DOM карточек и регрессии Cloudflare. После последней небольшой правки редактора отдельно прошли все 5 тестов редактора/сохранения. Браузерные сквозные проверки описаны выше. Иллюстрированный HTML-гайд проверен при ширине 1280 и 390 px.

`npm audit`: до обновления — 10 предупреждений, включая 2 high; после — **8 moderate, 0 high/critical**. Все оставшиеся предупреждения относятся к одной транзитивной цепочке сборщика: electron-builder → app-builder-lib → @electron/get → global-agent → roarr → sprintf-js. У sprintf-js 1.1.3 имеется предупреждение DoS через форматирование; исправленной опубликованной версии на момент проверки нет. Зависимость не вызывается кодом редактора. `npm audit --omit=dev` сообщает 0 предупреждений; Electron при этом является dev-зависимостью для сборки, но его runtime поставляется с приложением, поэтому этот результат не заменяет обновление Electron.

Не проверены в этой среде: portable EXE на Windows, нативные системные диалоги, реальное шифрование DPAPI, закрытие настоящего Electron-окна и публикация beta.3.6 в пользовательском аккаунте Cloudflare. Логика закрытия проверена отдельно; браузерная проверка не выдаётся за запуск EXE. Публикация beta.3.4 ранее подтверждена пользователем.

Остаётся архитектурное ограничение: вся база — один JSON, картинки встроены, все карточки присутствуют в DOM. Виртуализация и отдельное хранение изображений не реализованы. Аварийное завершение процесса может потерять ещё не отправленные правки. Публичная ссылка не является паролем; старые снимки Cloudflare могут оставаться доступными. Распространяемый EXE пока не подписан сертификатом.

## Воспроизведение

`npm ci` → `npm test`. Windows: `BUILD_RELEASE.bat` после backup данных и закрытия старой версии.

Браузерные проверки: `test/bench-100.mjs` и `test/e2e-100.mjs`. Требуют отдельной тестовой установки Playwright и Chromium; в runtime приложения они не входят. Можно указать `PLAYWRIGHT_MODULE` (путь к модулю Playwright) и `CHROMIUM_PATH` (исполняемый Chromium), либо использовать установленный пакет `playwright` и его браузер. Первый скрипт принимает путь к проверяемым исходникам и имя JSON-результата; второй — имя результата. Проверка работает на синтетических данных и временном хранилище.

Правила дальнейшей работы по пользовательскому гайду находятся в AGENTS.md; текущий план — PLANS.md. До правок сохранена baseline beta.3.5; итоговая история кода включена в HISTORY.bundle. Никаких пользовательских токенов или данных расследований в архиве нет.
