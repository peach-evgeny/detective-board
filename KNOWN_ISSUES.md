# Известные ограничения — Beta 3 (1.0.0-beta.3.6)

- Windows-сборка публичной беты пока не подписана коммерческим code-signing сертификатом. Windows SmartScreen может показать предупреждение «Неизвестный издатель».
- Основной целевой desktop-платформой этой беты является Windows. macOS/Linux пока не подготовлены как готовые пользовательские сборки.
- Публикация зависит от API Cloudflare. Автоматическое создание проекта может быть отклонено (в частности, 8000000); предусмотрен путь через существующий проект. Публикация beta.3.4 подтверждена пользователем; обновлённый Windows EXE beta.3.6 и его работа с аккаунтом ещё требуют проверки, см. VALIDATION.md.
- Это публичная бета. Перед важным обновлением рекомендуется использовать встроенную кнопку «Создать резервную копию». Не удаляйте системную папку Detective Board вручную.
- Очень большие изображения и чрезвычайно крупные доски могут требовать заметно больше памяти.


- Публичный экспорт пока является одним HTML: суммарно не более 25 MiB, включая встроенные изображения. Превышение блокируется до загрузки.
- Скрытие ранее опубликованного материала не удаляет исторические deployments Cloudflare. Ссылка является публичной, пароля игроков нет.
- Вход OAuth через Wrangler не встроен; используется минимально необходимый API Token. При недоступном шифровании ОС токен действует только до закрытия программы.
- Перенос backup на другой компьютер не переносит секреты и локальные привязки публикаций.
- Пропуск неизменённой публикации сравнивает локальный снимок. Если ветку изменили или удалили вручную в панели, измените доску перед повторной публикацией либо выберите новый проект. Управление внешними изменениями через Cloudflare здесь не синхронизируется.

- Полное хранилище пока записывается одним JSON; это ограничивает масштабирование. При крупных наборах данных первая запись может занять секунды, а вся доска и декодированные изображения занимают память. Виртуализация карточек и отдельное хранилище изображений не реализованы.
- В dev-зависимостях сборщика остаются 8 moderate-предупреждений одной цепочки `sprintf-js` (GHSA-hp3w-g68c-fv3c); исправленной версии пакета на момент аудита нет. В production-зависимостях npm audit не обнаружил предупреждений; это не гарантия отсутствия любых уязвимостей.
- Электронное окно ждёт сохранения при обычном закрытии; аварийное завершение процесса или отключение питания может потерять последние ещё не отправленные правки.
- Заголовок изображения проверяется по первым 256 КиБ. Необычные JPEG с очень большими метаданными могут потребовать пересохранения. Пределы данных описаны в UPDATING.md.
