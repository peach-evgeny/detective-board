# Detective Board 1.0 Beta 1

Первая публичная тестовая версия конструктора детективных расследований для мастеров настольных ролевых игр.

## Что умеет

- персонажи, места, улики, события, фотографии и заметки;
- визуальные связи, подписи и узлы-разветвления;
- факты с отдельной видимостью для игроков;
- этапы постепенного раскрытия расследования;
- «Истина мастера» и настоящая хронология;
- режим «Глазами игроков»;
- поиск, теги, фильтры, таймлайн и фокус по связям;
- PNG-снимки доски;
- отдельный интерактивный Player Viewer для игроков;
- мобильный просмотр Player Viewer;
- ручная и автоматическая публикация Player Viewer через Netlify;
- локальное автосохранение.

## Установка

Рекомендуемый вариант — скачать `Detective-Board-1.0.0-beta.1-Windows.zip`, распаковать архив и запустить `Detective-Board-1.0.0-beta.1.exe`.

Node.js, npm и отдельная установка зависимостей не нужны.

## Статус

Это публичная beta. Возможны ошибки и изменения интерфейса. Если нашли проблему, пожалуйста, создайте Issue и приложите шаги воспроизведения, скриншот и диагностику из программы.

## Известное ограничение

Приложение пока не подписано коммерческим code-signing сертификатом, поэтому Windows SmartScreen может показать предупреждение о неизвестном издателе.
