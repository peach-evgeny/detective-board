# Руководство пользователя Detective Board

## 1. Идея приложения

Detective Board разделяет расследование на два слоя:

- **Истина мастера** — полная версия произошедшего, включая секреты.
- **Знания игроков** — только то, что уже раскрыто в текущей сессии.

Мастерская программа всегда остаётся локальной. Для игроков создаётся отдельный Player Viewer, который можно открыть по ссылке с телефона или компьютера.

## 2. Создание дела

На главном экране нажмите **«Создать доску»** и задайте название расследования.

После открытия доски полезно начать с кнопки **▦ Конструктор дела**. Запишите:

- что произошло;
- кто виновен или какова истинная причина;
- мотив;
- способ;
- место и время;
- настоящую хронологию.

Этот раздел предназначен только мастеру и не публикуется игрокам.

## 3. Карточки

Слева доступны:

- Человек;
- Фото;
- Улика;
- Место;
- Событие;
- Заметка;
- Нить.

Карточку можно перетаскивать, масштабировать и поворачивать. Двойной клик по редактируемому тексту позволяет менять его прямо на доске.

### Быстрое построение большой схемы

Нажмите **ПКМ по существующей карточке**. В меню есть два быстрых сценария:

- **Добавить связь** → затем ЛКМ по уже существующему объекту, с которым нужно связать исходную карточку;
- выбрать тип новой карточки → новая карточка появится на курсоре уже с нитью. Переместите её и поставьте ЛКМ.

## 4. Факты

У людей, мест, событий и улик есть список фактов.

Для факта можно задать:

- текст;
- видимость игрокам;
- этап, с которого он становится доступен;
- карточки-источники — через что этот факт можно установить.

Это позволяет хранить на одной карточке и общеизвестные сведения, и будущие открытия.

## 5. Этапы раскрытия

В **Конструкторе дела** создайте этапы, например:

`Начало → Сессия 1 → После вокзала → Сессия 2 → Финал`.

Карточкам, связям и фактам можно назначить этап появления. Когда активный этап меняется, всё назначенное на него и предыдущие этапы становится доступно игрокам.

## 6. Связи

Нити описывают отношения между объектами. Базовые типы:

- Связано с делом;
- Знакомы;
- Родство;
- Работают вместе;
- Конфликт;
- Видели вместе;
- Владеет;
- Другое.

Чтобы соединить два существующих объекта обычным инструментом, нажмите **Нить**, затем ЛКМ по первой карточке и ЛКМ по второй. Связь создаётся сразу, после чего приложение автоматически возвращается в режим **Выбор**.

На нить можно поставить узел и создавать разветвления.

## 7. Проверка глазами игроков

Нажмите **👁 Игроки**. Мастерская доска перейдёт в режим просмотра и скроет сведения, которые пока не должны видеть игроки.

Повторное нажатие возвращает мастерский режим.

## 8. Публикация игрокам

Нажмите **«Экспорт игрокам»**.

### Автоматически через Netlify

При первом использовании понадобится Personal Access Token Netlify. В окне публикации есть кнопка **«Где взять?»**.

После первого подключения программа запомнит сайт для конкретного дела. В дальнейшем достаточно нажимать **«Обновить публичную доску»** — ссылка останется прежней.

### Вручную

Кнопка **«Экспортировать папку + ZIP»** создаст статический Player Viewer и ZIP-пакет для ручной загрузки на статический хостинг.

## 9. Player Viewer на телефоне

Игрок может:

- двигать доску одним пальцем;
- масштабировать двумя пальцами;
- нажимать на карточки;
- читать подробности на полноэкранной панели;
- искать объекты;
- смотреть таймлайн.

Редактировать мастерскую доску через Viewer нельзя.

## 10. Скриншоты

Кнопка **📷** позволяет сохранить:

- текущий вид;
- всю доску — программа сначала автоматически помещает объекты в кадр.

## 11. Поиск, фильтры и фокус

`Ctrl+F` открывает поиск. Панель фильтров позволяет оставить на доске только нужные типы карточек или определённый тег.

У выбранных объектов доступен режим исследования связей: посторонняя часть большой схемы приглушается.

## 12. Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` | Отменить |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Вернуть |
| `Ctrl+F` | Поиск |
| `Ctrl+C` / `Ctrl+V` | Копировать / вставить |
| `Ctrl+D` | Дублировать |
| `Delete` / `Backspace` | Удалить выбранное |
| `Space` + мышь | Перемещать камеру |
| Зажатое колёсико мыши | Перемещать камеру |
| Колесо мыши | Масштаб |
| `Esc` | Отмена действия / закрытие окна |

Горячие клавиши используют физические клавиши и работают при русской раскладке.

## 13. Данные, резервные копии и обновления

Доски сохраняются автоматически в одной постоянной системной папке **Detective Board**. Она не зависит от того, где лежит EXE или в какую папку распакована новая версия.

Откройте `? Как пользоваться → Данные и обновления`. Там доступны:

- **Открыть папку данных** — показывает реальное место хранения дел;
- **Создать резервную копию** — сохраняет переносимый JSON-backup;
- **Восстановить копию** — заменяет текущую базу выбранной копией; перед этим программа автоматически сохраняет текущее состояние;
- **Импортировать старый store.json** — добавляет доски из старых Preview/Beta к текущим делам.

Автоматические резервные копии создаются при смене версии и не чаще одного раза в день. Хранится до 30 последних автоматических снимков.

### Безопасное обновление

1. Закройте старую версию.
2. При важном обновлении нажмите **«Создать резервную копию»**.
3. Запустите новую версию.
4. Проверьте список дел и откройте нужную доску.
5. Только после этого удаляйте старый EXE или папку предыдущей версии.

Вручную переносить `store.json` между новыми версиями не требуется.

Если после старого Preview дела не появились, не удаляйте старую папку: найдите внутри неё `data/store.json` и импортируйте его через встроенную кнопку.

Подробнее: [UPDATING.md](UPDATING.md).

Данные мастера не отправляются в интернет, пока мастер сам не запускает публикацию Player Viewer. Публичная версия физически не содержит скрытых мастерских данных.

## 14. Настройки доски

Справа от названия дела находится кнопка **⚙ Настройки доски**. В Beta 2 здесь доступны пять параметров:

- цвет фона;
- цвет точек регулярной сетки;
- цвет **новых** нитей по умолчанию;
- цвет **новых** стандартных карточек по умолчанию;
- цвет текста **новых** стандартных карточек по умолчанию.

Фон использует ту же спокойную точечную сетку, что и главное меню. Существующие нити не перекрашиваются при смене значения по умолчанию: их цвет по-прежнему можно менять индивидуально в инспекторе. Уже созданные стандартные карточки тоже сохраняют свой цвет фона и текста. Заметки используют собственный отдельный цвет.

Настройки хранятся вместе с делом. Фон, цвета карточек и их текста передаются в Player Viewer. Более глубокая кастомизация отдельных элементов запланирована на будущие версии.
