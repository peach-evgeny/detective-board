# Detective Board 1.0 Beta 3

Публикуйте расследования через Cloudflare, обновляйте каждую доску по своей постоянной ссылке и работайте с большими досками без повторной загрузки картинок при каждом выборе карточки.

Третья публичная бета. Номер сборки — **1.0.0-beta.3.6**.

## Главное в обновлении

**Cloudflare Pages — основной способ публикации.** Для каждого дела создаётся независимая ссылка: обновление одной доски не заменяет другую. Настройки сохраняются между запусками; приложение показывает результат проверки подключения, ход публикации и понятные сообщения об ошибках. Неизменённая доска повторно не отправляется. Netlify остаётся дополнительным вариантом.

**Пошаговая настройка с иллюстрациями.** В комплекте есть `CLOUDFLARE-GUIDE.html`: где взять Account ID, какие права выдать API Token, как выбрать проект и проверить публикацию. Гайд открывается в браузере без интернета; для самой публикации интернет нужен.

**Быстрее работать с фотографиями.** Карточки сохраняют уже загруженные изображения при выборе и перемещении. На локальном тесте со 100 изображениями повторная отрисовка при выборе сократилась со 144 до 17 мс относительно предыдущей тестовой сборки beta.3.5. Это замер в Chromium на Linux, а не обещание одинаковой скорости на любом компьютере.

**Управляемое уменьшение изображений.** Новые картинки оптимизируются при добавлении. Старые можно уменьшить отдельной кнопкой с подтверждением и отменой через Ctrl+Z. При открытии дела они автоматически не пережимаются. Перед публикацией показывается примерный размер данных.

**Надёжнее сохранение.** Статус сохранения подтверждается после записи на диск. Ошибка записи не выдаётся за успех; правки остаются в редакторе для повторной попытки. Обычное закрытие ждёт сохранения, а перед удалением доски создаётся резервная копия. Повреждённое хранилище не заменяется пустым.

**Усилена защита локальных данных и экспорта.** Ограничен доступ к локальному API и системным действиям приложения, проверяются импортируемые данные и изображения. Удалены неиспользуемые части старого мультиплеера. В публичную доску по-прежнему входят только разрешённые игрокам сведения.

## Скачать и запустить

Скачайте **`Detective-Board-1.0.0-beta.3.6-Windows.zip`**, распакуйте архив и запустите `Detective-Board-1.0.0-beta.3.6.exe`.

Windows 10/11, x64. Node.js и отдельная установка зависимостей для готового EXE не нужны. Контрольные суммы EXE и ZIP находятся в приложенном `SHA256.txt`.

## Обновление с Beta 2 или тестовых сборок Beta 3

1. В старой версии создайте резервную копию: **«? Как пользоваться → Данные и обновления»**.
2. Закройте старую версию и распакуйте новую в отдельную папку.
3. Запустите новую версию, проверьте список дел, изображения, связи и настройки публикации.
4. Старую версию и резервную копию сохраняйте до успешной проверки.

Данные находятся в постоянной папке Detective Board. Если приложение сообщает о неподдерживаемых или повреждённых данных, не удаляйте их: порядок восстановления описан в [UPDATING.md](https://github.com/peach-evgeny/detective-board/blob/main/UPDATING.md).

## Что учитывать

- Это **Public Beta**. EXE пока не подписан сертификатом; Windows может показать предупреждение о неизвестном издателе.
- Публикация — снимок доски. Игроки увидят изменения после повторной публикации и обновления страницы. Подготовка версии на Cloudflare может занять некоторое время.
- У Cloudflare есть ограничения использования. Приложение проверяет размер публичного файла перед отправкой; подробнее — в гайде публикации.
- Публичная ссылка не защищена паролем. Скрытие ранее показанной улики не удаляет уже сохранённые игроками копии и старые deployments.
- Новые защитные пределы могут потребовать подготовки очень больших старых досок; оригинал при отказе проверки сохраняется.
