# Detective Board

**Detective Board** — настольная мастерская для конструирования детективных расследований в НРИ.

Мастер собирает полную картину дела у себя на компьютере: персонажей, места, события, улики, факты и связи. Затем постепенно открывает игрокам только ту часть расследования, которую они уже узнали, и при необходимости публикует отдельную интерактивную read-only доску для телефона или браузера.

> **Текущий релиз:** 1.0.0 Beta 1  
> **Платформа:** Windows 10/11  
> **Статус:** публичное бета-тестирование

## Для чего это приложение

Detective Board строится вокруг двух слоёв расследования:

- **Истина мастера** — полная версия произошедшего, включая секреты, мотивы и настоящую хронологию.
- **Знания игроков** — только то, что уже раскрыто на текущем этапе игры.

Это позволяет заранее построить преступление целиком, а затем открывать его игрокам постепенно, не создавая отдельную доску вручную для каждой сессии.

## Основные возможности

- бесконечная пробковая доска;
- карточки людей, мест, событий, улик, фотографий и заметок;
- нити, подписи и узлы-разветвления;
- быстрое создание уже связанной карточки через ПКМ;
- факты внутри карточек;
- отдельная видимость каждого факта для игроков;
- источники фактов — через какие объекты игроки могут получить информацию;
- этапы постепенного раскрытия расследования;
- «Истина мастера» и настоящая хронология;
- режим **«Глазами игроков»**;
- поиск, теги, фильтры, таймлайн и фокус по связям;
- Undo/Redo, копирование, слои и групповое выделение;
- PNG-снимки текущего вида и всей доски;
- отдельный интерактивный **Player Viewer** для игроков;
- мобильная навигация Player Viewer;
- ручная или автоматическая публикация Player Viewer через Netlify;
- локальное автосохранение.

## Быстрый старт

1. Создайте новое дело.
2. Откройте **«Конструктор дела»** и запишите, что произошло на самом деле.
3. Добавьте персонажей, места, улики и события.
4. Соедините связанные элементы нитями.
5. Добавьте к карточкам факты и укажите, какие из них видны игрокам.
6. Создайте этапы расследования: например, `Начало → Сессия 1 → После допроса → Финал`.
7. Проверьте результат через режим **«Глазами игроков»**.
8. При необходимости опубликуйте Player Viewer и отправьте игрокам ссылку.

Полное руководство: **[USER_GUIDE.md](USER_GUIDE.md)**.

## Секреты мастера и Player Viewer

Player Viewer создаётся как отдельная read-only версия дела. Скрытые мастерские данные не просто маскируются интерфейсом — они не включаются в публичный экспорт.

В Player Viewer не должны попадать:

- мастерские заметки;
- скрытые карточки;
- скрытые факты;
- скрытые связи;
- закрытые поля карточек;
- «Истина мастера».

Перед публикацией всё равно рекомендуется один раз включить **«Глазами игроков»** и проверить, что игрокам показывается именно нужная информация.

## Интернет нужен?

Для самой мастерской части — **нет**. Дела хранятся локально на компьютере.

Интернет требуется только для действий, которые сами обращаются к внешним сервисам, например для автоматической публикации Player Viewer в Netlify.

- фактическое поведение;

## Известные ограничения

См. **[KNOWN_ISSUES.md](KNOWN_ISSUES.md)**.

Главные ограничения Beta 1:

- Windows-сборка пока не подписана сертификатом;
